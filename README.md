# Keep in Touch

**Расстояния есть. Границ — нет.**

Интерактивный фронтенд-прототип социальной сети для знакомства с людьми по всему миру. Светлый интерфейс, мягкие фиолетовые акценты, оригинальные SVG-аватары и большой глобус с географически достоверными контурами материков.

## Запуск

Нужен **Node.js 20 или новее**. Сторонних зависимостей нет, `npm install` не требуется.

```powershell
cd "C:\Users\letsp\OneDrive\Desktop\The Fabulous\Keep_In_Touch"
npm run dev
```

Открой **http://localhost:5173**. Остановить сервер: `Ctrl+C`.

Если порт занят, в PowerShell:

```powershell
$env:PORT=5174
npm run dev
```

Открывать `index.html` двойным кликом не нужно: ES-модули и карта загружаются через локальный HTTP-сервер.

## Экраны и возможности

- **Главная / вход** — логин, пароль, показ пароля и кнопка «Пропустить и исследовать мир». Авторизация намеренно не реализована. Форма ничего не отправляет, пароль не сохраняется.
- **Поиск друзей** — интерактивный глобус, шесть вымышленных профилей, поиск по имени, городу и интересу. Фильтры «Все», «В сети», «По интересам» используют демонстрационные данные и интересы текущего профиля.
- **Глобус** — вращение перетаскиванием мышью или пальцем, изменение масштаба и сброс. При фокусе на глобусе: стрелки вращают, `+`/`−` изменяют масштаб, `Home` сбрасывает положение. Нажатие на аватар открывает карточку человека; все люди также доступны через обычный список.
- **Личный профиль** — редактирование имени, города, описания и интересов. Данные сохраняются в `localStorage` текущего браузера.
- **Симпатии** — локальные отметки, счётчик в профиле. Никаких реальных запросов дружбы и уведомлений.
- **Адаптивная верстка** — боковое меню на компьютере, нижняя навигация на телефоне. Учтены клавиатурное управление, фокус, модальные окна и настройка уменьшения движения.

## Технологии

HTML5, CSS3, JavaScript ES Modules, Canvas 2D. Node.js используется только для локального сервера и копирования статической сборки. Серверной логики соцсети, регистрации, базы пользователей и сообщений пока нет.

Все ресурсы локальные: во время работы не нужны CDN, картографические API, токены или интернет. Глобус использует ортографическую проекцию и заранее вычисленные точки суши, рисуется заново при взаимодействии; декоративный глобус вращается только когда видим и разрешены анимации.

## Структура

```text
Keep_In_Touch/
├── index.html                  # Разметка трёх экранов и диалогов
├── styles.css                  # Дизайн и адаптивные стили
├── app.js                      # Навигация, поиск, профиль и демо-данные
├── globe.js                    # Отрисовка и управление глобусом
├── assets/
│   ├── avatar-0.svg … avatar-6.svg
│   ├── favicon.svg
│   ├── land.geojson            # Исходная география Natural Earth
│   └── land-dots.json          # Точки суши для рендера
├── scripts/
│   ├── server.mjs              # Локальный HTTP-сервер
│   ├── build.mjs               # Сборка в dist/
│   └── generate-assets.mjs     # Пересоздание точек и SVG-аватаров
└── package.json
```

## Проверка и сборка

```sh
npm run check
npm run build
```

`check` проверяет синтаксис JavaScript. `build` собирает автономные статические файлы в `dist/`; эту папку можно разместить на статическом хостинге. Маршруты используют hash (`#welcome`, `#discover`, `#profile`) и не требуют серверного роутинга.

Для пересоздания графических ресурсов: `node scripts/generate-assets.mjs`. Для сброса демо-профиля и симпатий удали ключи `kit-profile` и `kit-likes` из localStorage сайта через инструменты разработчика браузера.

SVG-аватары и остальные графические элементы созданы для этого проекта. Имена, биографии и статусы людей вымышлены.
